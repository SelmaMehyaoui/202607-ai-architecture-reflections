# Results

Do not commit raw prompts or responses until they have been reviewed for
sensitive content and assigned opaque run identifiers.

Every result set must include:

- exact model and runner metadata;
- task-manifest revision;
- system and tool prompts;
- sampling and retry settings;
- raw tool traces and final responses;
- blinded rubric judgments;
- environment, latency, resource, token, and cost metadata where applicable;
- the pre-registered non-inferiority margin.

Generated result files should remain untracked until deliberately reviewed.
